# Проект Альфа

## Описание:
Проект Альфа - виджет банковских операций клиента, 
который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:lepinamv/HW_10.1.git
```
2. Установите зависимости:
```
poetry install
```
3. Создайте виртуальное окружение: 
Settings -> Project -> Python Interpreter -> Add -> Poetry Environment

## Тестирование
В проекте используются автоматические тесты для повышения качества и надежности кода. Фреймворк тестирования pytest.
